# Frontend

The frontend is an optional part of the assignment, implemented as a minimal React, TypeScript, and Tailwind UI for demonstrating the backend API routes and viewing their responses.

Its structure is intentionally simple: one App component contains four numbered steps for registering a schema, ingesting data, registering a dashboard configuration, and generating dashboard data. This keeps the implementation focused on exercising the API and displaying JSON results, with only the UI structure needed for this workflow.

See the [main README](../README.md) for setup, example requests, and test commands.
